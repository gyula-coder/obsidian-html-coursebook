Treat local HTML project folders as single interactive documents in Obsidian's native Files pane.

- Automatically detect `index.html` / `index.htm` and hide supporting files behind one document row.
- Open local scripts, styles, media, Canvas and interactive lessons in a separate browser view.
- Search entry-page text across courses, or find text within the current page.
- Reload changed resources while preserving the reading position where possible.
- Copy deep links, open in the default browser, and temporarily reveal source files.
- English and Simplified Chinese interface, following the app language.

Desktop only. Tested on macOS with Obsidian 1.15.0. Windows and Linux support has not yet been manually verified.

The plugin itself has no network requests, telemetry, accounts, payments or ads. HTML pages can load remote resources and reference local files, as they can in a browser. Only open trusted local HTML projects.

Install the three attached files into `.obsidian/plugins/html-coursebook/`, then enable HTML Coursebook under Community plugins.
